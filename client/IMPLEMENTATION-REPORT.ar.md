# تقرير إنجاز ومراجعة Kanbot

**تاريخ المراجعة:** 6 نوفمبر 2026  
**النسخة:** Frontend Review — React 19 / Vite / TypeScript Strict  
**النطاق:** مجلد `client/` فقط. لم يتم تعديل الـBackend.

## 1. النتيجة العامة

النسخة الحالية تحتوي على تغطية مصدرية واسعة لمتطلبات Kanbot v1، بالإضافة إلى ميزات اختيارية طلبتِ الاحتفاظ بها. لم أحذف أي ميزة إضافية من النسخة التي أرسلتِها.

لكن لا يمكنني تأكيد أن المشروع يجتاز التقييم بالكامل قبل تشغيل أوامر البناء والاختبارات والاتصال بالـBackend على جهازك. حاولت تثبيت الحزم، لكن الاتصال بسجل npm انتهى بمهلة، لذلك لم تُشغّل أدوات Vite/ESLint/Vitest محلياً في بيئة المراجعة.

التفصيل بنداً بنداً موجود في `REQUIREMENTS-AUDIT.ar.md`.

## 2. ما تم تعديله في هذه المراجعة

### أ. توافق المتطلبات الأساسية

- تحديث `react` و`react-dom` وReact type packages إلى الإصدار 19 وفق خطة التنفيذ.
- الإبقاء على TypeScript strict وVite.
- جعل الإنجليزية هي اللغة الافتراضية دائماً، وعدم تفعيل العربية تلقائياً حسب لغة المتصفح.
- الاحتفاظ بالعربية وRTL كإضافة اختيارية يفعّلها المستخدم يدوياً.
- إبقاء الـAPI layer منفصلاً عن مكوّنات الواجهة وعدم إدخال تغييرات على الخادم.
- الإبقاء على `.env.example`، وإزالة ملف `.env` المحلي من حزمة التسليم.

### ب. واجهة Calendar

أعيد تنظيم التقويم ليصبح مخططاً شهرياً مفيداً بدلاً من شبكة أيام بسيطة:

- ملخص أعلى الصفحة: المهام المجدولة في الشهر، المهام المفتوحة المتأخرة، المهام المكتملة في الشهر، والمهام المفتوحة بلا تاريخ استحقاق.
- فلاتر `All / Open / Done`.
- تنقل واضح بين الأشهر وزر للعودة إلى اليوم.
- دليل ألوان للأولويات، مع إبقاء نص المهمة ظاهراً وعدم الاعتماد على اللون وحده.
- اختيار يوم يعرض جميع مهامه في لوحة Agenda.
- فتح تفاصيل أي مهمة مباشرة من التقويم أو قائمة اليوم.
- عرض عدد محدود من المهام داخل خلية اليوم ثم إتاحة بقية القائمة في لوحة اليوم.
- تخطيط متجاوب للشاشات الأصغر، مع تكبير النصوص الصغيرة في عرض الهاتف.
- فصل الحسابات والتصفية والتجميع في `calendarModel.ts` وإضافة اختبارات وحدة لها.

**مصدر البيانات:** يستخدم التقويم تواريخ `dueDate` الموجودة في المهام، ويستخدم `completedAt` لحساب ما اكتمل في الشهر. لا يغيّر طريقة إنشاء المهام أو إدارتها ولا يحتاج إلى Backend جديد.

### ج. الخطوط والوضوح

- الإنجليزية: `Inter` للعناوين والنصوص.
- العربية: `IBM Plex Sans Arabic` مع ارتفاع أسطر أكبر.
- زيادة حجم النص الأساسي وبعض التسميات والنصوص الثانوية.
- رفع أحجام نصوص التقويم على سطح المكتب والهاتف، مع تحسين التباين باستخدام ألوان النص الثانوية.
- إضافة fallback إلى خطوط النظام إذا تعذّر تحميل خطوط Google.

### د. نافذة Complete Sprint

تم تعديل النافذة لتتوافق بصورة أوضح مع المرجع الذي أرسلتهِ:

- عرض عدد المهام المكتملة وغير المكتملة.
- عرض النقاط المنجزة من إجمالي نقاط القصة.
- اختيار وجهة المهام غير المكتملة باستخدام بطاقات اختيار Radio واضحة.
- `Backlog` محدد افتراضياً، وتظهر الدورات الأخرى فقط إذا كانت بحالة Planned.
- إظهار حالة تحميل وجهات النقل، وخيار إعادة المحاولة عند فشل تحميل قائمة السبرنتات.
- خيار `Generate AI summary` محدد افتراضياً ويمكن إلغاء تحديده.
- إصلاح حالة كانت تعرض رسالة «كل المهام مكتملة» أثناء تحميل وجهات النقل رغم وجود مهام غير منتهية؛ تظهر الرسالة الآن فقط عندما يكون عدد المهام غير المكتملة صفراً.
- بعد الإكمال ينتقل المستخدم إلى صفحة تفاصيل السبرنت.

## 5. ما لم أستطع تأكيده

حاولت تشغيل `npm install` أكثر من مرة، لكن طلبات سجل npm انتهت بمهلة اتصال. لذلك لم أتمكن من تأكيد:

- نجاح `npm run typecheck`.
- نجاح `npm run lint`.
- نجاح `npm test` باستخدام Vitest.
- نجاح `npm run build`.
- عمل كل طلب API مع Backend حي.
- المظهر الفعلي في المتصفحات وأحجام الشاشات المختلفة.

لا تعتبري المشروع جاهزاً نهائياً للتسليم حتى تنفذي هذه الفحوص على جهازك.

## 6. خطوات التحقق على جهازك

من مجلد `client/`:

```bash
npm install
npm run typecheck
npm run lint
npm test
npm run build
```

ثم شغّلي الـBackend من `server/`، وأنشئي `server/.env` بمفتاح Gemini عند الرغبة في اختبار AI الحقيقي. لا تضعي `AI_API_KEY` داخل مجلد client أو في متغير يبدأ بـ `VITE_`.

تأكدي أن Vite يعمل على `http://localhost:5173` وأن الخادم يعمل على `http://localhost:4000`، ثم اختبري تسلسل العرض التالي:

1. التسجيل وتسجيل الدخول واستعادة الجلسة بعد تحديث الصفحة.
2. إنشاء مشروع ومهمة وتعديلها وحذفها وإعادة ترتيب Backlog.
3. توليد مهام بالذكاء الاصطناعي ومراجعة المسودات قبل حفظها.
4. تخطيط Sprint ثم بدءه ونقل المهام بين الأعمدة الأربعة.
5. فتح `Complete Sprint` والتحقق من النقاط وخيارات النقل وملخص AI.
6. تجربة Calendar على 1440px و1024px و768px و390px.
7. تجربة Today وFocus وReports وTemplates وActivity واللغة العربية والوضع الداكن.
