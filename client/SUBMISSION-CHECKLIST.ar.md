# قائمة فحص تسليم Kanbot

> استخدمي هذه القائمة قبل عرض المشروع. لا تضعي علامة صح إلا بعد تجربة الخطوة فعلياً.

## قبل التشغيل

- [ ] تثبيت حزم الخادم وتشغيله من `server/`.
- [ ] ضبط `server/.env` بمفتاح Gemini إن كان المطلوب اختبار النموذج الحقيقي.
- [ ] التأكد من استجابة `http://localhost:4000/api/health`.
- [ ] تثبيت حزم الواجهة من `client/`.
- [ ] إنشاء `client/.env` من `.env.example`، ويحتوي `VITE_API_URL` فقط.
- [ ] تشغيل Vite على `http://localhost:5173`.

## أوامر الجودة المطلوبة

- [ ] `npm run typecheck`
- [ ] `npm run lint`
- [ ] `npm test`
- [ ] `npm run build`
- [ ] لا توجد أخطاء Console غير معالجة أثناء الاستخدام.

## السيناريو الأساسي المطلوب في العرض

- [ ] Register: إنشاء حساب جديد والتحقق من الحقول وكلمة المرور وتأكيدها.
- [ ] Login: تسجيل الدخول وإظهار أخطاء الخادم، ثم التأكد من استمرار الجلسة بعد Refresh.
- [ ] Projects: إنشاء مشروع وتعديله وتبديله وحذفه بعد تأكيد واضح.
- [ ] Backlog: إضافة مهمة سريعة بـ Enter، تعديل كل حقولها، البحث والتصفية وإعادة الترتيب.
- [ ] Todo details: التحقق من تنبيه التغييرات غير المحفوظة قبل الإغلاق.
- [ ] AI Generate: توليد مسودات، تعديلها، وتحديد العناصر المراد حفظها فقط.
- [ ] AI Plan: إدخال السعة والتركيز، تعديل الهدف، واختيار المهام قبل إنشاء Sprint.
- [ ] Start Sprint: إنشاء Sprint مخطط وبدؤه.
- [ ] Board: نقل بطاقة بين To Do وIn Progress وIn Review وDone، وتجربة البديل غير المعتمد على السحب.
- [ ] Complete Sprint: التأكد من عدد المكتمل وغير المكتمل ونقاط القصة، وتجربة Backlog وSprint مخطط وخيار AI Summary.
- [ ] Sprint History: ظهور الإحصاءات والمهام والملخص المحفوظ وإعادة توليده.
- [ ] AI Chat: تجربة Enter للإرسال وShift+Enter لسطر جديد وNew chat وMock AI badge عند الحاجة.

## الإضافات

- [ ] Today: التأكد من المهام المتأخرة واليوم والقادمة.
- [ ] Focus Mode: تشغيل المؤقت وإيقافه وتجربة فترات العمل والاستراحة.
- [ ] Calendar: اختبار شهر يحوي مهاماً، ويوم مزدحم، ويوم فارغ، والانتقال بين الشهور والفلاتر.
- [ ] Calendar responsive: فحص 1440px و1024px و768px و390px.
- [ ] Sprint Health / Capacity: تعديل السعة والتأكد من تنبيه تجاوزها.
- [ ] Reports: طباعة التقرير وتصديره، والتحقق من عدم ظهور عناصر الواجهة غير اللازمة في الطباعة.
- [ ] Templates: إنشاء مهمة من قالب وحفظ قالب جديد.
- [ ] Browser reminders: لا تفعّليها إلا بعد موافقة المستخدم على إشعارات المتصفح.
- [ ] Activity Log: تنفيذ تعديل والتحقق من ظهوره في السجل المحلي.
- [ ] Theme: تجربة الوضع الفاتح والداكن وألوان التمييز.
- [ ] Language: التأكد من الإنجليزية عند بداية الاستخدام، ثم تفعيل العربية يدوياً واختبار RTL.
- [ ] Keyboard: تجربة `Ctrl/Cmd + K` و`?` و`c` و`/` والتنقلات المختصرة.
- [ ] Accessibility: تجربة التنقل بـ Tab وShift+Tab وEscape والتأكد من ظهور focus.
